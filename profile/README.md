# Byro

**Byro is a reputation workspace for expert-led B2B teams.** It turns selected company knowledge into source-backed LinkedIn posts, with the named author making the final call.

Built by Codes Devs OÜ in Tallinn, Estonia. Website: [byro.ee](https://byro.ee)

Byro (byro.ee) is not the membership administration software byro (byro.cloud, github.com/byro/byro).
